## Lab1 — Полутоновые изображения

### Вариант 6

Класс полутоновых изображений произвольного размера.

**Поддерживаемые типы данных:**
`bool`, `char`, `float`, `short`

### Интерфейс класса

- Конструктор с параметрами: размеры изображения и флаг
  - `true` — заполнение случайными значениями выбранного типа
  - `false` — заполнение нулями
- Оператор `()` для чтения/записи элемента по индексам
- Операторы `*` (поэлементное «И» для `bool`) и `+` (поэлементное «ИЛИ» для `bool`) изображений
- Операторы `*` и `+` изображения на константу
- Оператор `!` для инвертирования значений изображения
- Вычисление коэффициента заполнения:
  `сумма значений / (количество ячеек × максимальное значение типа)`

### Особенности реализации

- **Контроль переполнения** при выполнении операторов `*`, `+`, `-`:
  значение ограничивается `std::numeric_limits<T>::max()` / `min()`.
- **Разные размеры** при сложении/вычитании: результирующее изображение
  имеет размер по большему из двух измерений.

### Задача 3

**Нарисовать закрашенный круг** с координатами центра `(x, y)` и радиусом `r`.
Значение для закрашивания задаётся пользователем.

Алгоритм: для каждой точки `(x, y)` изображения проверяется условие
`(x - cx)² + (y - cy)² ≤ r²`; если выполнено — записывается значение заполнения.
